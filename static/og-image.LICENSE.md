# Retruco social preview

`og-image.png` is a composition by Retruco using the Spanish playing-card artwork
by [Basquetteur](https://commons.wikimedia.org/wiki/User:Basquetteur), from
[Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:Spanish_playing_cards),
with SVG sources collected by
[gjenkins20](https://github.com/gjenkins20/spanish-playing-cards-svg).

The cards are resized, rotated, and arranged with Retruco's typography and colors.
