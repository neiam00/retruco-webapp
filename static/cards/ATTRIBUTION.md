# Spanish playing cards

Original artwork by [Basquetteur](https://commons.wikimedia.org/wiki/User:Basquetteur),
from [Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:Spanish_playing_cards).
SVG collection by [gjenkins20](https://github.com/gjenkins20/spanish-playing-cards-svg).
Licensed under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

The supplied artwork is retained as editable SVGs in `artwork/cards` in the
source repository. Gameplay uses lossless WebP copies rendered from those SVGs;
these derivatives retain the same CC BY-SA 3.0 license. Retruco uses the 40-card
Spanish deck (without eights or nines). Asset paths use “swords” for espadas.
